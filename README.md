# Blockchain App

A two-project .NET solution that visualizes blockchain concepts through an interactive web application and a companion command-line tool. The web app renders a live view of the blockchain in the browser, while the console utility processes transaction data independently as a self-contained Windows executable.

---

## Projects

### BlockchainApp — Web Application
A .NET Framework 4.8 ASP.NET web application that provides an interactive, visual demonstration of adding blocks to a blockchain. Hosted on IIS.

### BlockchainConsole — CLI Tool
A .NET 5 console application that reads and processes blockchain transaction data (sourced from `transactions.json`). Published as a self-contained `win-x64` executable.
